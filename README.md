# Paradise Nursery Shopping Application

A dynamic web application built with React and Redux for an online plant shop. 

## Features
* **Landing Page:** Welcoming interface with an "About Us" section and a "Get Started" button to enter the shop.
* **Product Listing:** Browse a variety of houseplants categorized by their care levels and environments.
* **Interactive Shopping Cart:** Built using Redux to manage state. Users can add plants, view total costs, adjust quantities, and remove items dynamically.
* **Responsive Navigation:** A persistent navbar that tracks the total number of items in the cart.
